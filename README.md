# Soft Computing Practicals

Practical work in Soft Computing using Python: linear neural networks, activation functions, McCulloch–Pitts threshold models, Hebbian and Delta learning rules, error backpropagation, associative Hopfield networks, Radial Basis Function (RBF) networks, Kohonen Self-Organizing Maps (SOM), Adaptive Resonance Theory (ART1), Perceptron classification, and Genetic Algorithms. Each practical is a separate PDF with the aim, concepts, procedure, Python code, output screenshots/plots, observations, and conclusion.
